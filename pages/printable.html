Printable Rainbow Sudoku

Color sudoku for paper. Pick a size, print, and fill every empty tile so that no color repeats in any row, column or thick-outlined box. Each board has exactly one solution, and every tile has a symbol too, so it works in black and white and for colorblind players. Each puzzle also has a link to play that exact board online.

Tips for printing

  • Crayon prints the starting tiles as colored outlines with a key, so kids color in every tile themselves and the printer barely uses ink.
  • Answer keys print on a separate page after the puzzles. Untick Answer key to leave them out.
  • The address bar keeps your sheet, so you can bookmark it or send it to a class and everyone prints the same puzzles.
  • Want a clock, hints and leaderboards? Play today’s daily online.
