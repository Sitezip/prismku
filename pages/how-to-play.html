How to play Rainbow Sudoku

Rainbow Sudoku is Sudoku with colors instead of numbers. Your job is to fill every empty tile so that no color repeats in any row, any column, or any outlined box. Each puzzle has exactly one solution, and you can always reach it by logic alone, with no guessing.

Controls

  • Tap a tile, then tap a color. Or tap a color first to paint several tiles: its border glows and a “tap to stop” bar appears. Tap that same color again, or the bar, to let go. Escape does this on a keyboard. Arrow keys move; number keys set a color.
  • ✏️ Notes drops tiny color dots in a tile so you can track the colors it could still be. Placing a color clears that dot from the tile’s row, column and box. With Notes on, ✨ Fill all notes (keyboard F) pencils every color that still fits each empty tile in one tap.
  • ⏱️ Beat your best. After your first solve of a size, the Time box shows your personal best (PB) for it, glows green while you're on pace, and pulses gold when the record is close. Beat it and the win screen tells you by how much.
  • 🔦 Spotlight a color. Pick a color, or tap a tile that already has one, and every tile of that color gets a ring while the empty tiles it can't go in fade out. Whatever stays bright is where that color can still go, so a lone bright tile in a row, column or box is a sure move.
  • 🌈 Watch for rainbow lines. When you fill the last tile of a row, column or box and it holds every color once, the line shimmers with a chime. It only checks the no-repeat rule, not the final answer, so it never gives the puzzle away.
  • Undo, Erase and Hint are there while you play. Restart turns off once the board is solved, so a finished puzzle stays filled. In Free play, Restart also starts the timer over; that restarted run is practice and stays off the leaderboard. On the daily the clock keeps running. A hint places one tile and tells you why it’s the right color, glowing the tiles that prove it, so each hint teaches a move you can spot next time. A hint adds 15 seconds, and placing a color that clashes adds 3 seconds.
  • The clock waits the first time you read the rules, before a board is shown. Once you’ve seen a board it keeps running until the puzzle is solved.

Beginner strategy

  1. Last color standing. Look for a row, column or box with only one empty tile. The missing color goes there.
  2. Scan one color at a time. Pick a color and look at where it already appears. Each copy rules out its whole row, column and box. Often only one tile is left for it.
  3. Only one fit. For a single tile, list the colors its row, column and box already use. If just one color remains, place it.
  4. Use notes on Hard and Expert. When two tiles in a region can only be the same two colors, those colors are locked there and can be removed from the rest of the region.
  5. Start big boards with ✨ Fill all notes. Any tile left with a single dot is solved: place that color, and its dot vanishes from every neighbor, often revealing the next single.

Quick Draw

Quick Draw is a reaction game built on one Easy box. After a random wait, a 2×2 box with red, blue, yellow and green appears with one tile empty; tap the missing color as fast as you can. Times are shown to the millisecond, tapping early is a false start, and a wrong color adds a second. Set a nickname to join the daily and all-time leaderboards.
